NOXERA STUDIOS — WEBSITE V0.2
================================

WHAT IS INCLUDED
- Responsive one-page website with 16 navigable sections.
- Black / red / white cinematic visual identity.
- Animated intro with Skip button.
- Hamburger navigation.
- French and English text toggle; browser language is detected on first load.
- AVERON presentation.
- Careers section with the recruitment contact email requested by the founder.
- News, media, team, roadmap, community, update history, showcase and legal sections.
- Reduced-motion support for visitors whose device requests it.

HOW TO OPEN ON WINDOWS
1. Extract the ZIP file.
2. Open the folder "noxera_studios_website".
3. Double-click index.html.
4. It should open in your browser (Edge, Chrome, Firefox).

IMPORTANT LIMITATIONS — THIS IS A FRONT-END PROTOTYPE
- The careers contact button opens the visitor's email application (mailto). It does not send or store applications automatically.
- The displayed recruitment address is public in this prototype because the founder requested it. Public addresses can receive spam. Consider replacing it with a dedicated studio mailbox before launch.
- The Control Center is specified in the project plan but is NOT implemented as a secure admin system in this static prototype.
- News, roadmap, status and team content are sample/static content. There is no database or live publishing yet.
- A real admin area, application inbox, authentication, database, file uploads and secure email delivery require a backend or trusted service. Never put passwords, API keys or secret tokens in front-end JavaScript.
- The domain noxerastudios.com is a target only; it has not been purchased or connected.
- Music is not bundled; no audio plays automatically.
- The gallery and several background visuals use remote Unsplash images and therefore require an internet connection. They are atmosphere/inspiration visuals, not official AVERON screenshots. Replace them with approved original game artwork before a public launch.
- Google Fonts requires an internet connection; fallback fonts are provided.

BEFORE PUBLIC LAUNCH
1. Review all studio and game descriptions for accuracy.
2. Replace placeholder artwork and example news with approved material.
3. Set up a domain and professional email with a parent/guardian.
4. Build and test a secure backend for admin and recruitment.
5. Add a privacy policy and legal details appropriate to the actual site and services.
6. Test on desktop, tablet and phone.
7. Obtain permission before publishing any team member's name, image or contact details.
